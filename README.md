# dev-prkim.github.io

myLiflow 앱의 개발자 웹사이트 (GitHub Pages).

| 파일 | 용도 |
|---|---|
| `index.html` | App Store 지원 URL · 마케팅 URL · 개발자 웹사이트 |
| `privacy.html` | 개인정보처리방침 (Notion 공개 페이지로 이동) |
| `app-ads.txt` | AdMob 판매자 인증. 도메인 **루트**에 있어야 해서 사용자 페이지 저장소(`<계정>.github.io`)를 쓴다 |
| `.nojekyll` | Jekyll 처리 없이 파일을 그대로 서비스 |
